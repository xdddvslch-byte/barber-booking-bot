# Barber Demo Bot — Telegram-бот запису на послуги

Демо-проєкт для портфоліо: клієнт записується на послугу в барбершоп, власник отримує сповіщення, бот сам нагадує клієнту про візит.

## Що вміє

**Клієнт:**
- обирає послугу, дату й вільний час (зайнятий і вже минулий час не показується);
- залишає ім'я і телефон (кнопкою «Надіслати мій номер» або вручну);
- переглядає й скасовує свої записи;
- отримує автоматичне нагадування за 2 години до візиту.

**Власник (адміністратор):**
- миттєве сповіщення про новий запис і про скасування;
- `/today` — записи на сьогодні, `/week` — на 7 днів.

**Захист:** двоє людей не можуть записатися на один час (це перевіряє сама база даних).

## Структура

| Файл | Що в ньому |
|---|---|
| `bot.py` | головний файл: логіка діалогу, команди, нагадування |
| `config.py` | **налаштування**: назва, адреса, послуги, ціни, графік роботи |
| `db.py` | робота з базою даних SQLite |
| `timeslots.py` | розрахунок вільних дат і часу |
| `phone.py` | перевірка українських номерів телефону |
| `keyboards.py` | кнопки |
| `.env` | секрети: токен бота і ваш ID (створюєте самі, на GitHub не потрапляє) |

Щоб переробити бота під іншого клієнта, здебільшого достатньо змінити `config.py`.

## Запуск на Windows 11, крок за кроком

### Крок 1. Створіть бота в Telegram
1. Відкрийте в Telegram **@BotFather** і надішліть `/newbot`.
2. Введіть назву (наприклад, `Barber Demo`), потім username, який закінчується на `bot` (наприклад, `barber_demo_ivan_bot`).
3. BotFather надішле **токен** вигляду `123456789:AAH...`. Це пароль вашого бота: нікому його не показуйте.

### Крок 2. Дізнайтеся свій Telegram ID
Напишіть боту **@userinfobot**, і він відповість числом `Id`. Це буде `ADMIN_ID`.

### Крок 3. Відкрийте проєкт у VS Code
1. Розпакуйте архів, наприклад у `C:\Projects\barber-bot`.
2. У VS Code виберіть **File → Open Folder** і вкажіть цю папку.
3. Відкрийте термінал: **Terminal → New Terminal**.

### Крок 4. Створіть віртуальне середовище й установіть бібліотеки
У терміналі виконуйте команди по одній:

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Після `activate` на початку рядка має з'явитися `(.venv)`.

> Якщо `activate` видає помилку про «running scripts is disabled», виконайте один раз
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, відповідайте `Y` і повторіть команду.
> Якщо `py` не знайдено, замініть його на `python`.

### Крок 5. Створіть файл `.env`
1. Скопіюйте `.env.example` і назвіть копію `.env`.
2. Впишіть свій токен і ID:
```
BOT_TOKEN=123456789:AAH...ваш_токен
ADMIN_ID=987654321
```

### Крок 6. Запустіть
```powershell
python bot.py
```
У терміналі має з'явитися `Бот запущено`. Відкрийте свого бота в Telegram і натисніть **Start**.

Зупинити бота: `Ctrl + C` у терміналі. Бот працює, лише поки ввімкнений ПК і відкритий термінал. Розгортання на сервер, щоб бот працював цілодобово, — наступний етап.

### Крок 7. Перевірте сценарії
- [ ] Записатися на послугу. Вам як адміну має прийти сповіщення.
- [ ] Спробувати записатися на той самий час з іншого акаунта. Цього часу вже не має бути в списку.
- [ ] «Мої записи» → скасувати. Має прийти сповіщення про скасування.
- [ ] `/today` і `/week`.
- [ ] Ввести неправильний телефон (`abc`). Бот має попросити ще раз.
- [ ] Нагадування: запишіться на час, до якого менше 2 годин. Нагадування прийде протягом хвилини.

## Завантаження на GitHub

```powershell
git init
git add .
git commit -m "Telegram-бот запису: перша версія"
```
Далі на github.com створіть порожній репозиторій **New repository** (без README) і виконайте дві команди, які GitHub покаже в розділі «…or push an existing repository».

Перед першим `git add` переконайтеся, що файл `.gitignore` на місці. Він не дає завантажити `.env` (токен) і `bookings.db` (дані клієнтів). Перевірити можна командою `git status`: `.env` у списку бути **не повинно**.
